## (a) 시나리오별 결과

개인정보 항목 수 = 응답 본문에 나온 이름 원문·실제 전화번호·상세 주소의 개수(0~3).

| 시나리오 | HTTP | 오류 코드 | 응답에 나온 개인정보 항목 수 | 비고 |
|---|---|---|---|---|
| 허브 스캔 | 200 | - | 0 | 권역만 표시 |
| 담당 기사 스캔 | 200 | - | 1 | 이름은 가림, 전화는 안심번호, 주소만 표시 |
| 비담당 기사 스캔 | 403 | NOT_ASSIGNED | 0 |  |
| 등록 안 된 기기 | 403 | DEVICE_MISMATCH | 0 | 담당 기사의 토큰을 다른 기기에서 사용 |
| 배송 완료 후 재스캔 | 410 | PII_REMOVED | 0 | 담당 기사가 다시 스캔 |
| 오늘 배정 없는 기사 로그인 | 403 | NO_ASSIGNMENT_TODAY | 0 |  |
| 비밀번호 6회 틀림 | 429 | TOO_MANY_ATTEMPTS | 0 | 1~5회는 401 INVALID_CREDENTIALS, 6회째 결과 |
| 위조 토큰 | 401 | TOKEN_INVALID | 0 | 다른 키로 서명한 JWT |
