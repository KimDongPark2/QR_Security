# server/ — QR 안심 운송장 중앙 서버 (담당: 이승엽)

작업 전에 `SERVER_SPEC.md`를 처음부터 끝까지 읽고, 그 문서를 기준으로 구현한다.

## 꼭 지킬 것
- `SERVER_SPEC.md` §7의 API(경로·요청·응답·오류 코드)는 팀원(앱 한승일, DB·웹 주승윤)과 맞춘 약속이다. 바꾸지 않는다. 바꿔야 하면 멈추고 `CHANGES.md`에 이유를 적은 뒤 보고한다.
- §9 단계 순서대로 만든다. 단계마다 `pytest`를 통과시키고 멈춰서 요약한다.
- 이름·전화번호·상세 주소 평문을 DB·로그·오류 메시지·허브/비담당 응답에 남기지 않는다.
- 데이터는 전부 가상이다.
- 이 폴더 밖(`../app`, `../db`, `../web`)의 파일은 만들거나 고치지 않는다.
- `.env`와 키는 커밋하지 않는다.

## 자주 쓰는 명령 (Windows)
- 가상환경: `.venv\Scripts\activate`
- 시드: `python -m app.seed`
- 서버: `uvicorn app.main:app --host 0.0.0.0 --port 8000`
- 테스트: `pytest -q`
